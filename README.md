# WordUp — תרגול אנגלית 🗣️

אפליקציית ווב (PWA, ניתנת להתקנה בטלפון) לתרגול אנגלית: מאגר מילים אישי, חזרה מרווחת, משחקים, משפטים, שמיעה, דיבור, שיחה עם AI — ושיתוף מילים בין משתמשים.

רצה על **Cloudflare Pages** + **Pages Functions**, עם **D1** (מסד נתונים) ו-**Workers AI**.

## פיצ'רים
- **מאגר מילים** — הוספה ידנית או עם ✨ AI (תרגום, חלק דיבר, משפט דוגמה), ייבוא רשימה בהדבקה, חבילות פתיחה מוכנות (~84 מילים), תגיות, חיפוש, סינון, מילים מסומנות.
- **חזרה מרווחת (SRS)** — כרטיסיות בסגנון Anki/SM-2: "שכחתי / קשה / ידעתי / קל".
- **משחקים** — בחירה מרובה, כתיבה, התאמת זוגות, אותיות מבולגנות, ספרינט 60 שניות, איש תלוי.
- **שמיעה** — "מה שמעת?", הכתבת מילים, הכתבת משפטים, סיפור AI מהמילים שלך עם שאלות הבנה.
- **משפטים** — בניית משפט, השלמת חסר, תרגום משפט מעברית, כתיבת משפט משלך עם בדיקת AI.
- **דיבור** — ציון הגייה למילים, Shadowing למשפטים, "תרגם בקול" (זיהוי דיבור בדפדפן).
- **שיחה עם AI** — תרחישים (ראיון עבודה בהייטק, ישיבת צוות, מסעדה, מלון...), בקול או בכתב, עם תיקון טעויות ותרגום.
- **שיתוף** — חבילות מילים עם קוד/קישור (ווטסאפ), ספרייה ציבורית, שליחת מילים ישירות למשתמש אחר (תיבת דואר).
- **סטטיסטיקה** — רצף ימים, יעד יומי, רמות שליטה, גרף 30 יום, המילים הכי קשות.
- סנכרון בין מכשירים, עבודה באופליין, גיבוי JSON/CSV, מצב כהה.

## הגדרה (פעם אחת)

### 1. טוקן של Cloudflare
ב-Cloudflare: **My Profile → API Tokens → Create Token → Custom token**, עם ההרשאות (Account):
- `Cloudflare Pages` — **Edit**
- `D1` — **Edit**
- `Account Settings` — **Read**

### 2. סודות ב-GitHub
ב-repo: **Settings → Secrets and variables → Actions → New repository secret**:

| שם | חובה | מה זה |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | ✅ | הטוקן משלב 1 |
| `CLOUDFLARE_ACCOUNT_ID` | ✅ | ה-Account ID (מופיע בדשבורד של Cloudflare, בצד ימין בעמוד Workers & Pages) |
| `SIGNUP_CODE` | אופציונלי | קוד הזמנה להרשמה. אם מוגדר — רק מי שיש לו את הקוד יוכל להירשם (מומלץ, כדי שזרים לא ישתמשו במכסת ה-AI שלך) |

אופציונלי: משתנה (Variables) `PAGES_PROJECT` לשם פרויקט אחר מ-`english-practice`.

### 3. פריסה
כל push ל-`main` מפעיל את ה-workflow, שיוצר אוטומטית את מסד הנתונים D1, מריץ את הסכמה, יוצר את פרויקט ה-Pages ומעלה.
אפשר גם להריץ ידנית: **Actions → Deploy to Cloudflare Pages → Run workflow**.

הכתובת: `https://english-practice.pages.dev`

## פיתוח מקומי
```bash
npm install
npm run db:local
npx wrangler pages dev
```
(פיצ'רי ה-AI דורשים חיבור ל-Cloudflare גם מקומית.)
